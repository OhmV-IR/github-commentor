# github-commentor

## Introduction

Provides a set of simple CRUD operation steps for interacting with Github comments on issues, pull requests and commits.

## Getting started

Install the plugin from the Jenkins update center, configure your default github token and username (or not if you prefer to provide credentials for individual actions).

## Issues

Report issues and request features via GitHub Issues.

## Contributing

Have common sense and follow the Jenkins contribution guidelines. Please be mindful that I have limited throughput for reviews and don't send tons of AI pull requests for me to check over.
